# Changelog

All notable changes to Dual Codex are documented here.

## 0.1.2 — 2026-08-06

- Added visible stage progress during orchestration.
- Accepted UTF-8 TOML files with or without a Windows byte-order mark.
- Added a Codex CLI prerequisite check to the profile setup script.
- Wrote profile configuration files as UTF-8 without BOM.
- Improved Windows setup and troubleshooting documentation.
- Added GitHub Actions tests for Python 3.11–3.13.
- Expanded credential and runtime-artifact ignore rules.

## 0.1.1 — 2026-08-06

- Added Windows support for npm-installed `codex.CMD` launchers.

## 0.1.0 — 2026-08-06

- Initial Architect → Executor → Reviewer prototype.
